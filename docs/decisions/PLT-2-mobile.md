# PLT-2 — 모바일 채널 결정: 웹 앱(PWA) 먼저

- 상태: 결정됨 (2026-09-29)
- 적용: `public/manifest.webmanifest`, 앱 아이콘(`public/icon*.png`, `public/icon.svg`), 서비스 워커 상시 등록(`src/main.tsx`), Capacitor 설정과 의존성 제거

## 배경

기존 Capacitor 설정은 앱을 만들 수 없는 상태였습니다.

- `capacitor.config.ts`의 `server.url`이 Lovable 개발 미리보기 주소를 평문 HTTP 허용(`cleartext: true`)으로 불러왔습니다. 앱이 아니라 원격 웹 페이지를 감싸는 구조였습니다.
- `android/` 프로젝트가 저장소에 없었습니다.
- 스피킹과 역할극은 브라우저 음성 인식(Web Speech API)을 쓰는데, Android WebView는 이를 지원하지 않습니다.
- 학습 알림(PRD-3)은 웹 푸시를 쓰는데, WebView에서는 동작하지 않습니다.

## 결정

**웹 앱(PWA)을 먼저 출시합니다.** 네이티브 앱은 아래 조건이 충족될 때 다시 검토합니다.

- 설치 가능한 웹 앱: 매니페스트, 192/512 아이콘(마스커블 포함), `standalone` 표시, 서비스 워커를 추가했습니다.
- Android Chrome에서는 "앱 설치"로 홈 화면에 추가할 수 있고, 웹 푸시 알림도 받을 수 있습니다.
- iOS(16.4 이상)에서는 공유 → "홈 화면에 추가" 후 웹 푸시 알림을 받을 수 있습니다.
- Capacitor 설정 파일과 `@capacitor/*` 의존성을 삭제했습니다. 잘못된 설정으로 스토어 빌드를 만드는 일을 막기 위해서입니다.

## 네이티브 앱을 다시 검토하는 조건

- PRD-2 지표에서 활성화와 D7 리텐션이 확인되고, 스토어 노출이 필요하다는 근거가 있을 때.
- 네이티브에서만 가능한 기능(백그라운드 음성, 위젯 등)이 필요할 때.

## 네이티브 빌드 체크리스트 (재검토 시)

1. 원격 URL(`server.url`) 없이 빌드 결과물(`dist`)을 앱에 포함하고, `android/`·`ios/` 프로젝트를 커밋합니다.
2. 음성 인식은 네이티브 플러그인(예: `@capacitor-community/speech-recognition`)으로 대체합니다.
3. 알림은 FCM/APNs 네이티브 푸시로 대체합니다(웹 푸시는 WebView에서 동작하지 않음).
4. 스토어 요구 사항: 개인정보처리방침 URL(`/privacy`), 앱 내 계정 삭제(프로필 > 계정 삭제)와 웹 삭제 경로, Google Play 데이터 보안 양식, 디지털 상품을 판매하면 인앱 결제 정책.
