# D1 — 제품 범위 결정: 핵심 학습 루프에 집중

- 상태: 결정됨 (2026-09-28), 적용 완료 (2026-09-29, PLT-1)
- 적용: 동결했던 기능의 코드·에셋·의존성·엣지 함수를 PLT-1에서 삭제했습니다. 기능 플래그(`src/lib/features.ts`)도 함께 제거했습니다.
  아래 "동결" 표의 "플래그" 열은 기록용입니다. 기능을 되살리려면 git 이력에서 복원합니다.
- DB: 펫·포인트·리더보드 관련 테이블과 함수는 사용자 데이터가 있어 삭제하지 않았습니다. 삭제하려면 별도 결정과 마이그레이션이 필요합니다.

## 배경

감사 결과, 코드의 약 43%가 펫(3D 모델, 상점, 옷장, AI 일기, AI 이미지)과 통계 대시보드에 쓰이고 있었습니다.
반면 제품의 차별점인 "내가 실제로 쓰는 표현으로 배우기" 루프는 결함이 있었습니다.
또 여러 AI 기능이 학습 경로 밖에서 비용만 발생시키고 있었습니다.
AI 추천은 대시보드를 열 때마다 호출되고, 주간 리포트는 기록되지 않는 데이터를 요약하고 있었습니다.

## 결정

제품을 **가져오기 → 내 카드 → 복습 → 연습** 루프로 좁힙니다.
이 루프 밖의 기능은 **동결**합니다. 동결된 기능은 화면과 라우트에서 숨기고, 코드는 PLT-1에서 삭제할 때까지 그대로 둡니다.

### 유지 (핵심 루프)

| 영역 | 경로 / 구성요소 |
|---|---|
| 모국어 분석·카드 생성 | `/import` (사전 테스트, 역할극 포함) |
| 간격 반복 복습 | `/cards` |
| AI 회화 (교정·피드백) | `/chat`, `/chat-history` |
| 스피킹 | `/speaking`, `/speaking-history` |
| 프로필 | `/profile` (닉네임, 목표, 알림) |
| 대시보드 | 복습 CTA, 빠른 학습, 목표, 스피킹 점수, 어휘 성장맵 |
| 통계 | SRS 건강, 활동 로그 |

### 동결 (숨김, 코드 유지)

| 기능 | 플래그 | 동결 사유 | 재개 조건 |
|---|---|---|---|
| 펫 전체 (`/pet`, 하단 탭, 대시보드 위젯, AI 펫 이미지·일기, 3D) | `pets` | 학습 경로 밖, 번들·AI 비용이 가장 큼 | 핵심 루프의 활성화·리텐션이 측정되고(PRD-2), 보상 루프가 필요하다는 근거가 생길 때 |
| 리더보드 (`/leaderboard`) | `leaderboard` | XP를 클라이언트가 조작할 수 있어 순위를 믿을 수 없음 | SEC-4(서버 권한 진행 원장) 완료 |
| AI 맞춤 추천 (대시보드) | `aiRecommendations` | 대시보드를 열 때마다 LLM을 호출하고, 캐시가 없음 | 서버 캐시와 사용량 한도(SEC-3) 적용 후, 효과가 측정될 때 |
| AI 주간 리포트 (대시보드) | `aiWeeklyReport` | 기록되지 않는(0인) 데이터를 요약함 | SEC-4로 학습 데이터가 실제로 기록될 때 |
| 통계 탭 7개: 학습 개요, 성과, 시간 분석, 활용률, 동기화 갭, 성장맵, 회화·스피킹 점수 | `extendedStats` | 조작된 지표(동기화율)가 있거나, 기록되지 않는 데이터를 읽거나, AI를 호출하거나, 다른 화면과 중복됨 | 개별 탭마다 실제 데이터와 사용 근거가 확인될 때 |

## 알려진 영향

- 포인트와 펫 경험치를 적립하는 코드는 그대로 남아 있습니다. 그래서 일부 완료 토스트에 "P 획득 / 펫 경험치" 문구가 계속 보입니다. 보상 로직은 SEC-4에서 서버로 옮기면서 함께 정리합니다.
- 동결된 경로로 들어오면(북마크 등) `/dashboard`로 이동합니다.
- 번들 크기(three.js, 3D 모델)는 이번 결정만으로는 줄지 않습니다. PLT-1에서 코드를 삭제하고 코드 분할을 적용할 때 줄어듭니다.
- 대시보드의 "언어 동기화율" 수치는 PRD-1에서 실제 지표로 바꿉니다.

## 후속 티켓

- PLT-1: 동결된 기능의 코드와 의존성 삭제, 코드 분할
- SEC-4: 이 결정으로 범위가 줄어듭니다. 펫 경제는 동결되므로 XP, 연속 학습, 학습 통계에만 집중합니다.
- PRD-1: 핵심 루프의 정확성 수정
